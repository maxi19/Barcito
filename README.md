para ejecutar la aplicacion

1-Generar el war con "maven install"

3-ir localhost:8080 en el browser -usuario admin -passowrd 123456

nota : para generar una imagen desde el docker fila ejecutar el siguiente comando
docker build -t mercadito-compras .
